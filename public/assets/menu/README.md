# 🎨 SudokuMap - Menu Background Assets

This directory contains background illustration assets for main menu cards and the slide drawer menu.

Users can place custom PNG files here with the exact filenames listed below to customize card background artwork:

- `bg_hero.png` (800x320 px) — Hero / Continue / Start Journey Card
- `bg_arena.png` (400x300 px) — Arena Card
- `bg_new_game.png` (400x300 px) — Free Mode / New Game Card
- `bg_clan.png` (800x240 px) — Clan Dungeon Card
- `bg_map.png` (800x240 px) — Adventure Map Card
- `bg_drawer.png` (500x800 px) — Slide Drawer Menu Background

If PNG files are missing, the UI automatically falls back to SVG vector artwork (`bg_hero.svg`, `bg_arena.svg`, etc.) in the same folder.
